The Loophole Bridge exposes a small, deliberate set of MCP tools over a Live
Set. This reference is generated from the server itself: a build step boots the
built server against `FakeLiveBridge`, calls the standard `tools/list` endpoint, and writes the
result to `tools.json`, which these pages render. This checks the registered library surface, not
the Extension Host or a running Live instance.

There are **{toolsData.length} tools**, grouped by what they touch. Reads carry
a `read` badge and writes a `write` badge. Writes serialize through the bridge; actual Live undo
entries remain an E2E gate.

## Categories

- [Tracks](/mcp/tools/tracks/): find, create, and set track properties.
- [Clips](/mcp/tools/clips/): list clips on a track and create a MIDI clip.
- [Notes](/mcp/tools/notes/): read and replace the MIDI notes in a clip.
- [Devices](/mcp/tools/devices/): insert a built-in device and set a parameter.
- [Transport](/mcp/tools/transport/): the Set overview and tempo.
- [Render](/mcp/tools/render/): bounce a track's pre-FX audio to a WAV.
- [Resources](/mcp/tools/resources/): read-only project state the model can
  browse without spending a tool call.
