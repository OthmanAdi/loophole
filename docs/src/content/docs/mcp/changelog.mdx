## Unreleased

No release is published yet, so there is no npm package or `.ablx` to download.
The MCP build produces a self-contained, library-only tarball that is exercised through an
isolated consumer check, while licensed SDK users package the extension locally. The tarball has
no supported executable or CLI and is not published.
The package and Live-runtime gates remain `NOT_RUN` and `NOT_RUN_NO_LIVE`.

Do not infer a package, CLI, `.ablx`, deployment, or release from this source page.

### Built so far

- The Loophole Bridge MCP server: 12 tools over tracks, clips, notes, devices,
  the song, and a pre-FX render, plus read-only resources and recipe prompts.
- The `LiveBridge` port and its in-memory `FakeLiveBridge`, so the same server
  code runs in CI and in Live.
- Five extensions in the Loophole Kit: Scale Lock, Humanize, Gain Stage Doctor,
  Session to Song, and Set Janitor.
- Finite and domain validation for every MCP numeric input before bridge calls.
