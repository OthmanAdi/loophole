How to batch rename tracks in Ableton with an AI assistant: describe the naming
you want and have the assistant resolve and rename the tracks, instead of
double-clicking each name field.

## What it does

The assistant reads the track list, decides the new names from your instruction,
and sets each track's name. Each `live_set_track_props` call is a separate mutation.

## The tool calls

1. `live_get_song_overview` (or `live_find_track`) to read the current track
   names and current opaque session references.
2. The assistant maps old names to new names from your instruction.
3. `live_set_track_props` per track to set the new name.

## Try it

> Rename every track that starts with "Audio" to "Gtr" plus its number, and
> rename "1-MIDI" to "Drums".

The assistant resolves each track and renames it. Review the mapping first, then inspect Live's
actual undo entries. Do not treat the batch as atomic.

## When to reach for the extension instead

For structural cleanup beyond names (empty tracks, clips that overrun their loop, and opt-in
palette enforcement only when a caller supplies a complete verified palette), the [Set Janitor extension](/extensions/set-janitor/)
sweeps the whole Set and fixes a selected checklist of issues. Janitor is the
hygiene sweep; this recipe is the targeted rename.
